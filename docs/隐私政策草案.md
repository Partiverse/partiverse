# 隐私政策(草案 v0.1)

> 状态:草案,待法务终审 | 适用:Partiverse 桌面应用(V1) | 日期:2026-10-08
> 结构性承诺:**我们没有用户账户系统,不运营存储用户数据的服务器**——数据流的默认归宿是用户自己的设备。

## 1. 我们收集什么

**不收集。** 应用不含遥测、埋点、广告 SDK。以下数据仅存于你的设备本地:

| 数据 | 存储位置 | 用途 |
|---|---|---|
| 云盘凭据(OAuth token/应用密码) | OS 凭据库(Keychain/Credential Manager/libsecret)+ rclone 加密配置(nacl secretbox) | 连接你的网盘 |
| 文件元数据索引(路径/大小/时间/哈希) | 本地 SQLite | 统一浏览与搜索 |
| Node 能力画像(健康/性能统计) | 本地 SQLite | 优化体验(架构 §12) |
| 应用设置 | 本地 | — |

## 2. 数据如何流动

1. **你 ↔ 云盘直连**:OAuth 授权与文件读写在你的设备与云盘服务商之间直接进行,不经我们中转(本地直连架构);
2. **引擎更新检查**:应用连接 rclone 的 GitHub Releases 获取版本信息,期间你的 IP 对 GitHub 可见;可关闭;
3. **云盘服务商**:你授权后,受各服务商自身隐私政策约束(建议阅读你授权的每家服务商条款);
4. **崩溃报告(V1 起,默认关闭)**:如你主动开启,仅上传脱敏的技术栈信息,不含凭据/文件名/路径(脱敏过滤器开源可审计)。

## 3. 你的控制权

- 断开即删除:移除某个 Node 连接时,本地删除对应凭据与索引缓存;
- 全量清除:卸载即全部清除(以上数据均不入系统全局目录之外的位置);
- 搜索索引可随时重建或清除;遥测/崩溃报告默认关闭且可独立开关。

## 4. 未成年人/法律适用

- 应用面向一般用户;我们(开发者)不处理、不掌握你的任何个人数据,故无数据出境、无第三方共享。
- 本政策为草案;正式版随 V1 发布经法务审订,并按分发渠道要求(如 App 备案信息)补充主体信息。
