## 2. 策略一致性检验(为何成立)

1. **AGPL-3.0 与产品形态自洽**:本地优先桌面应用不运营服务端,AGPL §13 对用户无感、对抄代码者有防御力;Alist 投毒事件后「开源、可审计、不碰用户数据」是市场稀缺信任溢价(01 §竞品、02 SWOT-S)。核心全开源是信任叙事的必要条件。
2. **闭源面足够小且「体验化」**:Pro 收体验与规模(账号数/传输/挂载/场景),不是安全或隐私功能——避开了 open-core 最常见的死法(核心能力藏进闭源导致社区版不可用)。
3. **双重许可当前法律上干净**:全量版权持有(无外部贡献),`partiverse-pro` 独立仓合成发行版合法——这正是 D39 把 CLA 前置的要害(见 §4 P0-2)。
4. **外部许可证风险已排雷**:rclone MIT 可闭源集成且运行时下载不分发(NOTICE);WinFsp 走 D16 引导安装避开 $6,000/3 年与 GPL 捆绑;OpenList 系 AGPL 禁链接复用;SQLite SEE 不采用(A6);deny.toml + 铁律 8 制度化拦截新风险。rclone 作免费商业引擎已被 RcloneView/rclone-ui 两度验证(04 §)。
5. **收入模型定调清醒**:¥300 万-1,000 万 ARR、支撑 4-8 人团队、「不是 VC 叙事的大品类」(02 §3.2)——与市场调研「小生意」结论一致。

## 3. PartiSync 联动检验(边界干净)

- **许可证无障碍**:PartiSync 全栈 Apache-2.0(05 §1),与 AGPL 单向兼容;唯一已发生复用 = caps.rs/error.rs ~200 行拷贝(ADR-0003,溯源标注 + 逐字节比对)。
- **边界已立宪(D27)**:CAS/同步/检索 AI/E2EE/扩展宿主一律消费 partisync crates 不另造;**商业化与全部 UI/UX 归 Partiverse 永久自有域**(05 §9.5)——PartiSync 保持纯 Apache-2.0 开源底座、不沾商业闭源,两边许可证关系永不会被 Pro 代码污染。这是整套开源/闭源策略的关键支点。
- **节奏匹配**:V1 零耦合 / V2 引 graph+cas / V3 引 index+ai+sync+ext-host(05 §三层协作),与付费墙(V2)、Pro 高级卖点(V3)时间线对齐;V3 自研量可砍 40-50%。
- **待收敛一处**:D17 终态(fork rclone 提上游 PR vs 转 OpenDAL service 一份代码双服务)三处文档表述一致但未落死(04/03/05),建议 backends-go 动工前裁定——它决定百度/123 后端的许可证归属表述。
