# Partiverse 前端 UIUX 规划(分阶段)v1.0

> 状态:✅ v1.0(2026-10-08)| 依据:两份市场调研(国际文件管理器与聚合工具/国内网盘 NAS 媒体场景,2026-10-08,来源随文内标注)| 适用:M1(V1)起,随版本演进
> 定位语:**透明、无墙、可解释**——把竞品的 Top 抱怨逐条反着做。

---

## 1. 设计原则(十条,均有调研依据)

1. **零登录、零开箱遥测**:不建账号体系,遥测默认关+显式开关——Spacedrive 强制登录与 Alist 隐藏遥测是品类两条血证(HN 2023 主帖;OpenList fork)。
2. **浏览永远先于索引**:任何 Node 接入即可在线直读浏览,索引只是后台增强——"先索引后可用"是 Spacedrive 被骂第一大 UX 罪。
3. **操作预览-提交**:跨 Node 复制/移动/批量操作先"投影结果"(文件清单/冲突方案/预计时长)再执行;这也是未来 AI 命令的安全壳(Spacedrive v3 operation validation)。
4. **一切失败可见、可重试、可诊断**:OAuth 过期前预警、断连黄标一键重连、失败给"人话"诊断步骤——rclone 系"静默重试无告警"是最高频抱怨。
5. **搜索即反馈**:本地索引结果即时返回,在线源声明范围+骨架+流式计数;对齐 Everything 式即时心智,做不到快就做到"看得见在搜"。
6. **传输全程透明**:进度/速度/瓶颈(限速?配额?风控?)可解释,内联在文件行,不做模态弹窗——国内"传输黑箱"与飞牛"受限但用户不知情"同为反面教材。
7. **无墙**:无广告、无看广告解锁、无清晰度锁、无续播会员化——国内网盘最大怨恨源(黑猫 1.8 万+ 投诉);Pro 边界在购买前明示。
8. **首页只做文件与任务**:零 feed 流、零内容推荐、零"热门资源"(国内网盘内容化全是反弹源,且涉监管风险)。
9. **高信息密度默认**:列表行内可见 名称/大小/时间/状态;留白是选项不是默认(国内工具语境,界面新闻)。
10. **键盘优先 + 无障碍基线**:W3C treegrid 模式(roving tabindex/aria-sort/aria-expanded),键盘完成 100% 操作;全局 ⌘K 命令面板。

## 2. 借鉴与规避清单(精简版,完整论据见调研纪要)

**借鉴**:Quick Look 空格预览(Finder);标签页+Home 聚合(Win11);Miller 列 hover 扩展(OneCommander);双栏 Commander+可命名/可复用/可定时任务卡+通知引擎(MultCloud/Rclone UI 3.7);连接健康徽标+一键重连;Node 树内嵌网盘(飞牛"像本地云盘一样")+云/本地图标区分;播放进度记忆免费+同名外挂字幕自动加载+原画/转码状态标注(爆米花/Infuse 范式);提取码一键复制+剪贴板自动填充(百度分享范式);刮削失败给改名建议(TMDB 命名规范)。
**规避**:强制登录/开箱遥测;首页内容化;窗口内广告与"看广告换权益";会员墙嵌主链路;静默重试;右键菜单慢且深;"先索引后可用";挂载后状态不可见;AI 让用户干等;概念词汇超载(只用 Node/Particle/Placement 三个自造词)。

## 3. 信息架构与窗口结构(V1)

```
┌─ 自绘标题栏(三端统一,平台行为保留)──────────────────────┐
│ [⌘K 命令面板] [标签页 +]                    [Node 健康] [设置] │
├────────┬────────────────────────────────────┬───────────────┤
│ Node   │  工具行: 面包屑 · 视图切换(列表/网格) · 排序 · 搜索 │  详情面板      │
│ 侧栏   │  ┌──────────────────────────────┐  │ (可收起):      │
│ ·本地  │  │ 文件列表(treegrid,高密度)      │  │ ·缩略图/元数据 │
│ ·云盘① │  │ 名称·大小·修改时间·Node·状态    │  │ ·Particle/驻留 │
│  ⚠黄标 │  │ (内联取回进度/冲突角标)        │  │ ·哈希指纹      │
│ ·S3    │  └──────────────────────────────┘  │ ·操作入口      │
│ ──────  │  [底部: 传输条(聚合进度,点开队列)]   │               │
│ +添加Node│                                   │               │
└────────┴────────────────────────────────────┴───────────────┘
全局: ⌘K 面板(搜文件/搜命令/搜 Node)· 空格预览 · 标签页 · 双栏(V2)
```

- 首页=上次浏览位置(无推荐位);侧栏 Node 按"本地/网盘/协议"分组,云图标+容量条;**健康徽标常驻**(绿正常/黄即将过期或降级/红断连,点击=诊断面板)。
- 破坏性操作(删除/覆盖)一律进预览-提交对话框;回收站类能力以 Node 实际能力位为准,没有就不显示(诚实原则)。

## 4. 核心界面与流程规范(V1)

### 4.1 添加 Node 向导(按类型分支,全部 ≤3 步)
- OAuth 类(OneDrive/GDrive/Dropbox/Box/pCloud/MEGA):内嵌本地回调授权;GDrive 明示 `drive.file` 限制+自建 client 引导(Q2)。
- 百度:授权页展示 code→用户复制回填(oob 式,本地换 token);完成提示"当前可访问范围:/apps/{appname}(沙箱)",Node 详情页显示实际授权范围(债2/债4)。
- 123(**仅 WebDAV**,✅Owner 修订):引导用户到 123 网页端生成应用专用密码→回填端点+账号+密码;**端点域名占位提示"从 123 控制台复制"**,不硬编码;UI 注明"123 官方 WebDAV 为 VIP 权益"。
- 协议类(SMB/FTP/SFTP/WebDAV/S3):schema 自动生成表单(`config/providers`),高级项折叠;坚果云标注官方配额(600 次/30 分钟)。
- 完成即"连接体检"(轻探针):列出该 Node 的能力位(哈希/直链时效/配额),失败给诊断步骤。

### 4.2 浏览
- 列表(默认,高密度)+网格(图片目录);虚拟化列表;**慢源渐进加载**:先出缓存壳+骨架行,在线结果流式补齐;排序默认修改时间倒序,名称排序用拼音+自然排序(数字 file2<file10),杜绝中英文方向不一致 bug。
- 右键菜单:≤8 项常用+收口,响应 <100ms(Win11 教训);多选批量操作走底部操作条,不藏二级菜单。

### 4.3 搜索(WP08)
- ⌘K 与搜索框同源;结果三区:本地索引(即时)/在线 Node(声明"正在搜索 X,已找到 N")/命令;空态给"未建索引?去建"引导而非空白。

### 4.4 传输(WP06)
- 底部聚合条+队列面板;每任务:方向图标/源→目标/进度/速度/**可解释状态**(限速中-该盘限流/排队-预算器/重试中-直链刷新);失败行内"重试/查看原因";跨 Node 大操作先预览-提交(冲突:跳过/覆盖/重命名/两者保留)。

### 4.5 预览(WP07)
- 空格键 Quick Look 式:图片/文本/Markdown/PDF/音视频;视频底部条显示"原画直连"或"转码中",失败给原因;进度记忆免费。

### 4.6 掌控面板最小版(WP09)
- 入口=侧栏顶部仪表:总空间水位、各 Node 健康与容量条、异常清单(token 将过期/配额将满/接口异常),红点聚合,点开即处理动作。

## 5. 全局交互规范

- **无障碍**:treegrid 全套 ARIA;全部功能可键盘完成;焦点可见;对比度 AA。
- **状态四态**:每个异步区域必须有 空态/加载态(骨架)/错误态(可重试)/成功态,禁止空白沉默。
- **主题**:暗色优先+亮色,另设独立"护眼"暖色开关(国内双开关心智);高信息密度默认,"宽松"为可选布局。
- **文案**:状态说人话+可解释("正在等待百度网盘响应(该接口限流 8 次/分钟),已自动排队"),禁黑箱术语;Pro 功能标"Pro"角标,点击见价格页,免费功能永不弹升级窗。
- **三端策略**:自绘标题栏+平台差异表(Ctrl/Cmd、托盘行为、原生文件对话框);Linux 重点验证 Wayland/NVIDIA(参照 Rclone UI 兼容清单)。

## 6. V2 UIUX 预规划(挂载/传输增强/媒体)

1. 挂载向导+**托盘状态窗**(挂载点/缓存水位/断连告警)——挂载不可"无界面";
2. 传输任务对象化:可命名、可保存为模板复用、可定时(cron)→ 触发 OS 原生调度(Rclone UI 3.7 范式),完成/失败通知引擎(系统通知+可选 webhook);
3. 掌控面板完整版:空间分析(大文件/重复粒)、去重建议(同 Particle 多驻留)、Node 对比视图;
4. 媒体模式:影视目录自动切海报墙(豆瓣评分+年份+大小),刮削失败给 TMDB 规范改名建议;字幕同名自动加载+在线搜字幕;启播速度与长播稳定为验收项(爆米花痛点清单);
5. macOS 挂载 Beta 的引导安装流(WinFsp/FUSE-T,07 审计 A1/A2)。

## 7. V3 UIUX 预规划(AI/全端)

1. **AI 混合模式**(Ask Photos 教训):传统搜索即时返回,AI 语义异步增强并以"补充结果"合并,可关闭;
2. 自然语言整理→**计划卡片**(预览-提交):"把上个月的截图归档"先生成变更投影,确认才执行;执行可撤销;
3. E2EE 保险箱:锁屏/解锁交互、恢复短语流程(参考 Cryptomator 体验);
4. 插件市场:能力白名单可视化("此插件可读索引/写云端"),minisign 验签状态展示;
5. 移动端:延续 Node/Particle 概念,移动优先场景=搜索+预览+传输进度。

## 8. 设计系统与工程落地

- **令牌**:色彩(品牌色+语义色+Node 类型色)/字阶/间距/圆角/阴影一份 tokens.json,三端共用;暗色为默认基调;
- **组件(✅D25,2026-10-08 选型)**:**shadcn/ui 为基座**(MIT;Tailwind v4+React 19 完全兼容;Command=cmdk 命令面板;Context Menu/Dialog/Sheet/Form 全覆盖;2026-07 起可选 React Aria 原语底座补 a11y)+ **TanStack Table v9(getExpandedRowModel)+ TanStack Virtual 做虚拟化 treegrid**(唯一大缺口,路径成熟:虚拟化必须跑在展开后的扁平行模型上、ARIA 语义按 W3C APG 手写或借 React Aria Tree)+ **react-hook-form+zod** 动态 schema 表单(连接向导);主题=语义 CSS 变量+`[data-theme]`(暗色+护眼暖色各一份变量表,成本 1-2 天)。纪律:组件最小定制、业务放 wrapper、升级走 `shadcn diff`、关键界面过 axe+读屏测试。备选路径:AntD(treegrid 零自研但风格重)、HeroUI v3(rclone-ui 先例但组件面窄)。评估详情见选型调研(2026-10-08);
- **性能预算**(及格线,写进 WP 验收):冷启动 P95<1.5s;万行列表滚动 60fps(虚拟化);目录首屏 <300ms(缓存壳);⌘K 响应 <100ms;
- **工程护栏**:React 严格模式;ESLint 含 jsx 安全插值规则(继承 partisync ui_hardening 方法论);Storybook 或等价物登记核心组件;GUI 验收=实操+截图归档(AGENTS 硬规则)。

## 10. V1-V4 长远铺垫(UI 架构预留,✅Owner 指令 2026-10-08:设计考虑长远)

V4 主攻桌面深度期(多引擎槽位/媒体中心/NAS 远程引擎,OEM),V5 候选生态/团队(蓝图 docs/10)。以下预留项在 **V1 就按"存在感最低、扩展成本最低"的方式落地**,避免 V2-V4 推翻重来:

1. **侧栏分区预留**:侧栏分组=「本地/网盘/协议」之外预留「设备与团队」(V5 多设备)与「场景库」分组锚点(V1 只显示文件与照片馆/文档库入口,分组结构一次到位);
2. **引擎槽位可见性**:V1 单实例,但设置页含「引擎」节(版本/缓存目录/诊断),数据模型自第一天携带 slot id——V4 多槽位时 UI 只需枚举槽位,不改导航;
3. **媒体中心 IA 预留**:预览播放器组件按"可成长为转码队列/字幕工作流宿主"设计(播放器=独立可嵌入 surface,不是页面内孤件);影视库场景的详情页预留 转码状态/字幕管理 槽位;
4. **IPC 命令面版本化与命名空间**:specta 生成命令按 `browse/transfer/search/profile/scenes/engines/team` 命名空间注册,前向兼容;V1 只实现 browse/transfer/search/profile;
5. **场景框架挂点**:V1 的照片馆/文档库即跑在场景框架上(09 设计),侧栏场景入口、视图切换器、卡片模板机制一次做对——V2 影视/书房是加配置不是改架构;V4 场景包(声明式)在同一 schema 上开放;
6. **远程引擎预留**:Node 类型枚举保留 `remote-engine`(V4:partisd on NAS 的远程连接形态),连接向导模板占位不实现;
7. **i18n 基建(✅D29 修订)**:V1 全部文案走资源文件(day-one),**唯一语言包=English,严禁混排**;zh-CN 字典待 UI 稳定后(V1 末或 V2)加入——为 OEM/国际化铺路的同时保证语言一致性;
8. **tokens.json 可扩展**:场景包(V4)未来需要主题变量注入,tokens 分层=核心层(应用)/场景层(可注入)从 V1 分开。
