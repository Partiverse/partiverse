## 2. 鉴权(两套体系,严禁混淆)

### 2a. 平台级(open_platform,自有账号)
- 换 token:`POST https://open-api.123pan.com/api/v1/access_token`(Header `Platform: open_platform`,Body `{clientID, clientSecret}`)→ `{accessToken, expiredAt}`
- access_token **30 天;同一 client_id 最多 3 个在用 token**(多颁发会踢下线,token 计入设备数);**无 refresh_token,过期前重新获取**
- 所有请求:`Authorization: Bearer <token>` + `Platform: open_platform`

### 2b. 用户级 OAuth(挂载应用,企业专属)
- 商务发 appId/secretId → 授权地址 `https://yun.123pan.com/auth?client_id=...&redirect_uri=...&scope=user:base,file:all:read,file:all:write`
- `POST /api/v1/oauth2/access_token`(authorization_code / refresh_token);**refresh_token 90 天单次有效**;刷新后旧 access_token 立即失效;access_token 有效期以 expires_in 返回
- 官方已接入方:Infuse、网易爆米花、网易云音乐、VidHub、CloudDrive

## 3. 核心接口(域 `https://open-api.123pan.com`,均带 Platform 头)

| 能力 | 端点 | 要点 |
|---|---|---|
| 文件列表(推荐) | `GET /api/v2/file/list` | parentFileId 必填(根 0);limit≤100;**lastFileId 游标**(-1 末页);非递归;**结果含回收站文件,按 trashed 过滤**;searchData 全局搜索 |
| 文件详情 | `GET /api/v1/file/detail`;`POST /api/v1/file/infos`(批量) | etag=**MD5**;status>100=审核驳回 |
| 上传 V2(推荐) | `POST /upload/v2/file/create`(etag=MD5)→ `reuse`(秒传)/`preuploadID`+`sliceSize`+`servers` → `POST <域名>/upload/v2/file/slice`(sliceNo 从 1,sliceMD5)→ `POST /upload/v2/file/upload_complete`(completed=false 间隔 1s 轮询) | 单文件 10GB;文件名<256 字符、禁 `"\/:*?|><` |

## 4. 限流(预算器参数,官方公开表)

- **平台级 QPS**([开发须知] 2026-01-29):user/info 10、file/move 20、file/delete 10、file/list(v1) 10、**file/list(v2) 15**、mkdir 20、access_token 10、转码 1-20;超限 **429**,401=token 无效
- **OAuth 挂载应用限流**(同 uid,企业通道):upload create 5、get_upload_url 20、mkdir 5、delete 1、list(v1) 1、**list(v2) 15**、infos 10、download_info 5;oauth2/access_token 100 次/分,**触发限流会封 IP**
- 社区实测(rclone PR #9047,2025-12):免费账号 download_info 2 QPS、upload create 1、complete 5;VIP 更高(upload 20、download_info 不限)
- 另有**非会员自用下载 1GB/天**(5113)

## 5. 条款与官方态度

- 文档库明文:**"禁止调用非 OpenAPI 接口列表中的其余非公开接口。审查人员查询到后会做封号处理"**
- 2025-09 防盗链升级(直链解析批量失效;官方公告原文未能核实);2025-11 免费权益缩水(30GB→10GB/月等);2026-04 有集中封号报道;2026-09-28 专业空间规则调整致歉
- → 只走 OpenAPI 白名单接口;直链场景优先 download_info 而非抓取网页直链

## 6. rclone PR #9047(社区实现,参考价值高)

- 状态:closed 未合并(2025-12-16~2026-05-12;ncw 曾表态 CI 绿即合,因官方停发免费 key 无法集成测试而搁浅);代码在其作者 fork(Higanoneko/rclone master)
- 端点与官方文档完全一致(见 §3);流程要点:MD5 秒传、**不支持修改时间、不支持 0 字节文件**、按 VIP 自适应限流、>100MB 用磁盘临时文件、实测 1TB 上传成功(--transfers 2)

## 7. 官方 WebDAV(主轨,2026-10-08 核实)

| 项 | 事实 |
|---|---|
| 定位 | 官方公开功能:"国内唯二支持 WebDAV 协议的网盘,任何支持 WebDAV 的软件均可访问"(官网原文) |
| 门槛 | **VIP 及以上**(免费用户无);2026 年 VIP 连续包年 258 元(2026-01 涨价后),用户自付 |
| 开启 | 网页端 →「第三方挂载」→「WebDAV 授权管理」→ 添加应用(自定义名)→ 选授权目录 → **生成应用专用密码(只显示一次,可随时撤销)** |
| 端点 | 按账号个性化,如 `https://webdav-{账号ID}.pd1.123pan.cn/webdav` 或 `https://webdav.123pan.cn/webdav`——**引导用户从控制台复制,不硬编码域名** |
| 鉴权 | HTTP Basic:账号=注册手机号/邮箱,密码=**应用专用密码**(非登录密码,按应用隔离) |
| 能力 | 读/下载/上传/播放已多客户端验证(RaiDrive/VidHub/Infuse/Zotero);细粒度能力无官方清单;**无秒传/分片/回收站/离线下载**(这些仅 OpenAPI 有) |
| 限制 | 免费用户全端 10GB/月(2025-11 起);**会员 WebDAV 专项流量额度官方未公布**;速度波动(个案 50KB/s~上传 20Mbps);大目录易 503;官方客服自认"WebDAV 协议不稳定" |
| 已知兼容问题 | rclone 经其 WebDAV 下载失败个案(2023 issue,服务端问题);Alist 中转上传报错/列目录不全;LibreOffice 经 OpenList WebDAV 报 HEAD 错 → **Partiverse 必须做重试/断点/目录分页缓存,WP11 实测** |
| 条款 | 用户协议禁止"以营利为目的直接或间接向第三方提供…WebDAV…等能力"→ **Partiverse 定位=用户用官方功能连自己的账号:不托管凭证、不中转聚合、不把 123 能力包装成收费卖点、不绕限流** |
| 技术对接 | 经 rclone webdav 后端接入(D8:引擎覆盖,零自研);Node 画像 caps 全部走 WebDAV 通用能力位 |

### OpenAPI vs WebDAV 差距速查

| 维度 | OpenAPI(权益包 ~¥20/月,仅自账号) | WebDAV(VIP ¥258/年,任何用户) |
|---|---|---|
| 适用对象 | 开发者自有账号 dogfood | **普通 VIP 用户(主轨)** |
| 上传 | v2 分片+MD5/SHA1 秒传+单步≤1GB | 单流 PUT,无秒传 |
| 下载 | download_info 直链(非会员 1GB/天) | WebDAV GET,受会员流量额度(未公布) |
| QPS | 官方公开表(list v2=15 等) | 未公布,速度波动 |
| 回收站/离线下载/转码/图床 | 有 | 无 |
| 政策风险 | 高(2026 刚付费墙化,已有第三方因此停源) | 中(功能公开宣传,但额度随时可调) |
