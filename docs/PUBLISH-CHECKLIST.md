## 执行方式

1. 移动文件至私有仓(partiverse-planning,建议私有 git);
2. 公开仓内对应位置留一行"内部文档,不入公开仓"(不留内容摘要);
3. 运行敏感信息扫描(密钥/测试账号/内部域名);
4. 公开版 README 文档索引收敛:移除对已移出文档(01/02/04/05/07/10/11 及 reviews/reports)的索引链接,替换为一行占位说明;
5. Owner 终审后才可 push public。
