- 交付定义=SPEC DoD+质量 bar+parity 清单三重通过。

### D37 版本与发布纪律(✅Owner 指令:严格管理,杜绝跃升)
- SemVer;蓝图版本映射:V1/V2/V3/V4 ↔ `1.0`/`2.0`/`3.0`/`4.0`;M1 开发期用 `0.x`。
- **预发布通道**:alpha(功能未齐,内部/内测,**数据格式可破坏**)→ beta(发布范围功能齐,数据/配置格式冻结,扩大测试)→ rc(只修阻断 bug,**零新功能**;发现新功能=回退 beta)→ stable(GA)。
- **升版纪律**:①版本号只在里程碑关账/发布签核时变化,普通 PR/任务**禁止触碰版本号**;②**无实质功能交付不升 minor/patch**;③破坏性变更(数据格式/IPC/配置)必须发生在 alpha 阶段且升 minor;④dev 构建 `0.0.0-<shortsha>+dev`,不入册、不参与比较;⑤升版唯一入口=发布签核(Owner),记录于发布报告+简报;⑥应用内显示通道徽标(alpha/beta)。

## B. 工程注意事项(进 SPEC/任务卡,不拍板)

1. **文件名策略(跨 Node 传输的暗坑)**:macOS NFD vs 其他平台 NFC——CJK 文件名跨盘拷贝可能产生"双胞胎";传输引擎统一归一+冲突探测(WP06 核实 rclone 相关参数);各 Node 非法字符表(123 禁 `"\/:*?|><` 等)入 provider KB 通用节,目标侧净化策略=默认拒绝并提示/可选自动替换(预览-提交中呈现);
2. Windows MAX_PATH(260)与云超长路径:长路径策略 WP06;
3. 大小写不敏感目标盘的同名冲突(Same/sAME):入冲突策略与预览;
4. 自有 SQLite **schema 版本化+迁移纪律**(sqlx migrate,学 partisync v1→v18 惯例);不支持降级(明示);
5. 日志策略:本地轮转(位置/大小/保留期)+脱敏过滤器(token/密钥必脱,文件名按等级);`--use-json-log`;
6. 错误码目录 P-ERR-xxx 从 WP03 起维护(UI/日志/诊断共享);
7. 并发:同目标路径任务互斥;引擎单写者(rcd 独占 config)已保证 token 单写;
8. 时间:mtime 显示本地时区、比较用 epoch;mtime 缺失=0 口径(继承 partisync);
9. 电量/计费网络感知(自动暂停传输)→V2 backlog;
10. 快捷键映射表(平台差异)入 WP05;axe+读屏冒烟入 GUI 验收协议;
11. 首次运行零状态引导(无 Node 时的 onboarding)入 WP05 任务卡;
12. 诊断包格式(脱敏日志+环境摘要+画像快照)入 WP09/WP10。
