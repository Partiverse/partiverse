# ADR-0008 WP05 前端依赖集与 window_state 拷贝件声明

- 状态: 接受 | 日期: 2026-10-10 | 负责人: @partiverse
- 背景: M1-WP05-T01(数据接线+window_state 搬运+前端依赖 ADR)。卡内 ③ 要求前端新依赖逐个 registry 实测 license+商业授权核查+deny 涉及面说明;② 要求 window_state 搬运件按 ADR-0003 同款纪律在本 ADR 声明。依赖选型基座=D25(2026-10-08,08-前端UIUX规划 §8:shadcn/ui+TanStack Table v9+TanStack Virtual+react-hook-form+zod+cmdk)。
- 决策(运行时依赖,app/package.json):新增 **@tanstack/react-table 9.2.8**(钉 ^9 大版本;虚拟化 treegrid 扁平行模型)、**@tanstack/react-virtual 3.14.13**、**cmdk 1.1.1**(⌘K 命令面板,shadcn Command 底座)、**react-hook-form 7.89.0**+**zod 4.6.5**(连接向导动态 schema 表单)。开发依赖:**vitest 5.0.3+jsdom 30.1.2+@testing-library/react 16.3.3**(DoD④ 单测基建,视觉断言不做)、**eslint 10.12.0+typescript-eslint 8.71.1+eslint-plugin-react-hooks 7.1.1**(DoD⑤ 工程护栏:jsx 安全插值 no-restricted-syntax 封死 dangerouslySetInnerHTML/innerHTML/document.write 逃逸口+react-hooks/flat.recommended+`--max-warnings 0` 零 warning 门)。jsdom 为 RTL DOM 测试的必要支撑件,eslint 栈为 08 §8 护栏载体,均随本 ADR 一并声明。
- 证据(2026-10-10 本机 `pnpm view <pkg>@<ver> license` 经 npmmirror registry 逐个实测,非记忆):11 个直接依赖 license **全为 MIT**(@tanstack/react-table/@tanstack/react-virtual/cmdk/react-hook-form/zod/vitest/jsdom/@testing-library/react/eslint/typescript-eslint/eslint-plugin-react-hooks);安装版本 peerDeps 实测相互兼容(eslint 10 由 typescript-eslint `^10.0.0` 与 react-hooks `^10.0.0` 明示支持)。商业授权核查:全 MIT,零付费许可/年费/审核费/主体证书要求,**无 07 审计表新增条目义务**(铁律 8 的备选方案条款不触发;D25 已裁定基座,备选 AntD/HeroUI 维持否决记录)。cargo deny 不涉:deny.toml/cargo-deny 仅作用于 Rust workspace(根 CI 五门禁第 5 节),pnpm 侧依赖不入其扫描面——本 ADR 的 registry 实测即其 license 门。
- 决策(window_state 拷贝件,卡内 ②):`app/src-tauri/src/window_state.rs`(278 行——审查 [low] 修正原记 282)拷贝自 <https://github.com/Partiverse/partisync> `crates/partisync-desktop/src/window_state.rs`,基线 commit `d7f73ffd516ae455e9774f635332453bede6cfc1`(git show 只读取件;Apache-2.0,Copyright PartiSync contributors,同组织);标注头与正文间 1 行空行分隔(不入逐字节比对),正文与上游逐字节一致,唯一代码级适配=测试模块以 std 临时目录等价物替换 `tempfile::TempDir`(免新增 Rust dev 依赖/铁律 8,三处测试断言逐条保留;测试临时目录无 drop 清理语义,运行残留由 OS 策略回收(审查 [low] 显式取舍)),模块 doc 注释零改动。纯函数(capture_from 等)与 WindowStateStore 契约逐条搬,7 个单测全绿。**本卡未接线窗口事件**(卡面「仅模块归属适配」;接线将触发 AGENTS 桌面端 GUI 实操验收义务,归后续任务),`pub mod` 导出避免死代码告警。
- 影响: 正向=T02(浏览虚拟化)/T03(向导+⌘K)依赖面就绪且许可干净;window_state 后续接线时仅改 lib.rs 装配与 data-dir 路径,拷贝件本体不再触碰。代价=①前端依赖升级随上游(锁文件 pnpm-lock.yaml 已入库);②eslint 栈大版本升级需复跑护栏探针;③window_state 接线被推迟为显式债务,运行报告已登记。CI 桥接:src-tauri 独立 workspace 三门禁(cargo check/clippy -D warnings/test)本卡本地自跑归档,入 CI 仍属 WP01 债务(不改 ci.yml);前端 lint/test 脚本已就位,是否入 CI 五门禁由 Owner 排期(本卡不改 CI)。
