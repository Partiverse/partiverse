# 商业授权审计与备选方案(Audit of Commercial-Licensing Exposure)v1

> 状态:v1(随选型持续更新) | 日期:2026-10-08
> **原则(✅ Owner 指令 2026-10-08)**:所有隐含商业授权的部分必须增设备选方案;**自研为最终保底**。
> 保底优先级 = ①官方付费许可(最省力) → ②开源替代 → ③自研(只做"卡脖子预案",不轻易启动)。
> 执行规则:新依赖引入(铁律 8 的 ADR)必须同步更新本表;无备选方案的"隐含商业授权"依赖不得合入。

---

## A. 已确认选择中的商业授权点(逐项:首选/备选/自研保底)

### A1. WinFsp(Windows 挂载,V2)
- **性质**:GPLv3+FLOSS 例外;与专有软件捆绑分发需商业许可($6,000/3 年/组织≤10 人)。
- **首选(✅D16)**:引导用户自行安装 WinFsp(分发解耦,零费用)。
- **备选**:购买商业许可改为捆绑(仅当引导安装的转化/体验数据证明不可接受)。
- **自研保底**:Windows Cloud Files API(cfapi)占位文件自研实现(Rust windows-rs;工作量大,c-api 已被 OneDrive 验证)。**启动条件**:法务否决引导安装 且 商业许可不批。

### A2. macOS 挂载(V2)
- **性质**:macFUSE(GPL 系,引导安装)或 FUSE-T(**许可待核实**,列入 Phase 0 核实清单)。
- **首选**:`rclone nfsmount` + FUSE-T/macFUSE 引导安装(许可核实后定)。
- **备选**:仅应用内浏览、不做 macOS 挂载(V1 即此形态,天然兜底)。
- **自研保底**:自研用户态 NFS 服务端 + 系统 `mount_nfs`(FUSE-T 同思路,绕开全部第三方 FUSE 授权;远期工程)。

### A3. Google Drive 全量 scope 的 CASA 安全评估(V2 才触发)
- **性质**:年度审,约数百美元/年(第三方实验室)。
- **首选**:V2 预算内通过(✅D7:V1 停留 `drive.file`)。
- **备选**:永久停留 `drive.file`(自研保底=接受"仅管理本应用创建的文件"限制,引导用户自建 client 独享配额;功能受损但零费用、零依赖)。

### A4. Apple Developer Program(macOS 签名/公证)
- **性质**:$99/年;公证是 macOS 分发的体验门槛。
- **首选**:个人账号($99/年,D11 不阻塞)。
- **自研保底**:无签名分发 + Gatekeeper 手动放行文档(体验差,仅作为不能付款时的过渡)。

### A5. Windows 代码签名(需主体)
- **性质**:OV/EV 证书年费数百美元且需公司主体(✅D11 待办)。
- **首选**:主体落地后购 OV/EV。
- **自研保底**:自签名证书 + SmartScreen 说明文档(过渡)。

### A6. 索引库加密(当前**不采用**,Q3)
- **性质**:官方 SQLite SEE 为商业授权($2k+ 量级)。
- **首选**:V1 不加密(凭据才敏感,ADR 记录)。
- **备选**:**SQLCipher(BSD,免费)**——若未来需要整库加密,首选此项而非 SEE。
- **自研保底**:敏感字段应用层加密(AES-GCM,密钥入 keychain)。

### A7. 支付与收款(国内付费墙,主体依赖)
- **性质**:微信/支付宝商家收款需企业主体;海外 MoR(如 Paddle)为抽成模式(非许可,列作费用)。
- **首选**:主体落地后开国内商家;之前海外走 MoR。
- **自研保底**:免费开源+赞助/爱发电通道(过渡形态)。
