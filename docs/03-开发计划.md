## 1. 产品定位

### 1.1 一句话定位

**一个把本地磁盘、NAS/协议存储、对象存储和各大云盘聚合成统一文件浏览器(统一浏览、统一搜索、统一整理、统一传输)的桌面优先应用;凭据只存本机,文件不过我们的服务器。**

### 1.2 基线决策(✅ 已全部确认,2026-10-08)

| # | 决策项 | 推荐基线 | 备选 |
|---|---|---|---|
| D1 | 目标市场 | **国内优先**,海外为自然延伸 | 海外优先 / 双市场同步 |
| D2 | 接入策略 | **纯官方 API+标准协议**;逆向渠道不内置,预留社区驱动插件机制(显式风险提示) | 官方为主+实验性逆向 / 逆向优先 |
| D3 | 首发平台 | **桌面三端(Win/mac/Linux,Tauri 2.x)**;挂载分期(见里程碑) | Windows 单端先行 / 移动优先 / Web 优先 |
| D4 | 商业模式 | **开源核心(GPL 系)+商业 Pro 订阅**;终身买断为辅 | 纯闭源订阅 / 买断为主 |
| D5 | 产品名 | Partiverse(暂定) | [待确认-D5] |

## 4. 技术架构与选型(v0.2,详见 [rclone 选型评估](./04-rclone选型评估.md))

**引擎策略:多云能力不复用自研 adapter,改为编排 `rclone rcd` 守护进程(unix socket + rc API)。** rclone(MIT,65+ 后端,官方 rclone-ui 已验证 Tauri 2.x 同构集成)承担国际云、协议存储、对象存储的协议实现、VFS 缓存、传输与校验;自研面收敛为"国内开放平台盘 + 上层索引/搜索/整理/编排 + UI"。

| 层 | 选型 | 理由 |
|---|---|---|
| 桌面壳 | Tauri 2.x | 与官方 rclone-ui 同栈,sidecar 集成路径有官方样板 |
| UI | TypeScript + **React(✅ D6)** | 与官方 rclone-ui 同栈,可参照其 rclone-sdk 交互模式 |
| 多云引擎 | **rclone rcd sidecar**(MIT;运行时按版本下载至应用数据目录,便于引擎热更新) | 消除自研协议层;AI 代理可解析其全链路结构化 JSON(schema/错误/日志/lsjson) |
| 国内开放平台盘 | **fork rclone 写 Go 后端(百度/123,阿里过审后)+ 提交上游(✅ D17)**;provider 知识沉淀独立知识库,为未来转 OpenDAL Rust service(选项③)铺垫 | 123Pan PR #9047 实证上游只缺"可测试性";合并后维护成本转移给社区 |
| 上层核心 | Rust:统一索引(SQLite+FTS5)、配额预算编排(按盘 tpslimit/令牌桶)、传输任务编排(rc job)、重复检测 | rclone 无跨盘索引/搜索,这是我们的护城河层 |
| 凭据 | rclone config 加密(nacl secretbox)+ 主密码入 OS Keychain/Credential Manager/libsecret,经 `RCLONE_PASSWORD_COMMAND` 注入 | 官方原生方案,token 刷新自动写回加密文件;禁用 obscure |
| 数据面 | `rclone serve http`(127.0.0.1)+ `--vfs-cache-mode full`(稀疏缓存) | Range/206 已源码实证,支撑流式播放与预览随机读 |
| 挂载 | rclone mount(Linux FUSE / macOS nfsmount+FUSE-T / **Windows:rclone mount + 引导用户安装 WinFsp,✅ D16**) | cfapi 自研列为后续可选项,不进近期计划 |
| 更新 | 应用自更新(GitHub Releases/官网)+ 引擎独立热更新 | 备案约束下国内分发走官网 |

仓库结构(建议 monorepo):

```
partiverse/
├── app/             # Tauri 壳 + 前端 UI(含由 config/providers schema 自动生成的"添加云盘"表单)
├── core/            # Rust:index(FTS5)/ quota-scheduler / transfer-orchestrator(rc job)/ dedupe
├── engine/          # rclone 编排:rcd 生命周期(unix socket)、健康探针、引擎热更新、升级 CI
├── backends-go/     # fork rclone 的 Go 后端:baidu(openapi)、123pan(openapi);同步向上游提 PR
├── mount/           # rclone mount/nfsmount 包装与自动重挂
├── mobile/          # V3:android / ios
└── docs/            # 本文档等
```

关键机制:
1. **配额预算编排**:预算器在应用层按 provider 限速调度对 rc 的请求(坚果云 600 次/30 分钟 ~ Google 12,000 次/60 秒 相差 4 个数量级),索引/浏览/搜索统一走预算器;
2. **索引策略**:有 delta API 的盘增量;无 delta 的按 mtime+size 对比(`lsjson` 抓取);首次建索引按盘并行、可暂停;搜索只查本地索引;
3. **引擎健康监控**:`rc/noop`+`core/version` 探活;挂载 resume 失联自动重挂;VFS 缓存水位监控(缓存上限为软限制,防盘满);后端失效在 UI 显式降级提示。
