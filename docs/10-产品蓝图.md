## 0. 蓝图原则

1. **每期交付"用户可见的完整形态"**,不做无用户面的纯地基期(每期都有可安装、可日用的版本);
2. **闸门制**:进入下一期前对照上一期验收指标+外部环境(平台政策/竞品/监管)重估主题;
3. **主题可变,原则不可变**:透明/无墙/可解释、合规红线、纯 AI 开发模式、partisync 互补分工;
4. 单期时长 3±1 个月;期数编号 M{m} 与任务卡编号一致。

## 2. 各期形态细描

### M2 · 「整理与传输」(对应 03 计划 V2)
- **用户拿到的**:安装后除了"看遍",还能 ①在任意两个 Node 间发起可保存的传输任务(命名/定时/完成通知);②把常用云盘挂成系统盘符(Windows cfapi 之外的 WinFsp 路线 + Linux);③视频直接流式播放;④一键找出所有重复 Particle 并处理;⑤影视/书籍目录自动变成海报墙/书架。
- **商业化**:Pro 上线(免费=3 Node+基础浏览;Pro=无限 Node/传输任务/挂载/场景解锁)——价格带按 D4(¥99-198/年),买断选项并行。
- **依赖闸门**:①百度/123 审核与权益包状态重估(123 仅 WebDAV 已降低依赖);②法务终审结论(跨 Node 复制的呈现边界);③M1 指标:周活跃跨源操作≥X、驱动可用率≥99%、崩溃率<0.1%。

### M3 · 「智能与全端」(对应 03 计划 V3)
- **用户拿到的**:①"用一句话找文件"即时+异步混合;②"把上个月截图归档"→计划卡片→一键执行;③手机上看得到、搜得到、传得动;④NAS 式双向同步与备份任务;⑤保险箱(E2EE);⑥装插件扩展动作;⑦音乐厅与自建智能视图。
- **技术形态**:partisync crates 进入(index/ai/sync/ext-host,✅D19-D22);移动端 DocumentsProvider/FileProvider。
- **依赖闸门**:①M2 付费转化≥2% 验证商业模式;②partisync 向量检索"暂缓"拍板是否随 M3 解除(与其 roadmap 协同);③移动端商店审核环境(主体备案前置,✅D11)。

### M4 · V4 桌面深度期(2027 下半年,✅Owner 定向)
- **用户拿到的**:①多引擎槽位——重度用户的"传输专用引擎+浏览引擎"分离、工作区隔离(Pro);②媒体中心:转码队列可视化、字幕工作流(搜索/时间轴/特效轨)、与影视库场景深度合流;③NAS 场景:partisd 部署在 NAS,桌面 Partiverse 远程连接( 家庭资产的常驻中枢 ),并开放 OEM/渠道合作;④大库性能(10⁶ 文件级)与桌面打磨。
- **生态/团队位置的调整**:声明式场景包(09 设计 §3)作为 V4 后期功能提前引入(门槛最低的生态能力);完整生态期与团队期顺延 V5,按 V4 数据二选一或分期。
- **依赖闸门**:①M3 商业化与健康指标;②WinFsp 引导安装转化数据(决定是否升级捆绑);③partisd 实体化成熟度(远程引擎依赖它,这也是向 partisync 建议的第一优先方向,见 05 §9.5);④partisync 向量检索/移动端 roadmap 协同结果。

## 3. 跨期不变项(蓝图迭代时的"宪法")

1. 合规红线五条(02 §4.4);2. 设计原则十条(08 §1);3. 凭据零明文/本地直连架构;4. 规格驱动+反走捷径流程;5. Partiverse=产品/PartiSync=底座分工(D19)+能力边界宪法(D27);6. 每小版本提交简报。

## 3.5 交付 Benchmark(✅Owner 指令:每版发布前对照并归档)

**质量 bar(每版全量测量)**:冷启动 P95<1.5s;万行列表 60fps;索引搜索 P95<300ms;空载内存<500MB;安装包<40MB;崩溃会话率<0.1%;驱动可用率(周)≥99%。每项附测量方法(脚本或人工协议),发布报告含实测值。

**Parity 锚点(交付形态的对标线)**:
| 版本 | 对标 | 对照内容 |
|---|---|---|
| V1 | rclone-ui;Finder/Explorer | 核心功能对齐表(浏览/连接/传输管理);基线交互(剪切粘贴/type-to-jump/标签页/排序/空格预览) |
| V2 | CloudDrive2/RcloneView;Quick Look | 挂载流程与稳定性、传输队列、任务复用/定时 |
| V3 | MultCloud;Dropbox Dash | 任务体系完备度、混合搜索感受、移动端 |
| V4 | Jellyfin/Infuse(媒体中心);NAS 厂商 | 海报墙/刮削纠错/转码字幕工作流、远程引擎体验 |

**交付定义 = SPEC DoD + 质量 bar + parity 清单 三重通过**;对照报告归档 docs/reports/,随简报呈 Owner。

## 4. 蓝图维护规则

- 每期启动前 2 周产出该期正式 SPEC(M1-WP00 模式),蓝图条目转为 SPEC 才可开发;
- 外部触发器(平台政策突变/竞品重大动作/监管变化)可随时发起期中蓝图修订,修订走 Owner 拍板并更新本文件版本号;
- 本文件不是承诺:对外沟通口径以当期 SPEC 与发布说明为准。
