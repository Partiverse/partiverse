# [M1-WP03-T02] JobManager:job 状态机+启动对账+SQLite 落库
- 所属: M1-WP03 | 风险级: R1(含 schema 首版,铁律 7 知会;jobs 表不含凭据与文件内容,V1 索引不加密口径 ADR-0002) | 预估: L
- SPEC: docs/specs/M1-WP00.md#WP03(JobManager 部分);docs/06-架构设计-Phase0草案.md §3 JobManager 条+§7 任务队列行
- 目标(DoD): ①JobManager(partiverse-core 新模块 jobs.rs):generic 异步 rc job——submit(method,params) 经 T01 RcClient 以 `_async:true` 提交取得 jobid;状态机严格四态 queued→running→done|error(非法迁移拒绝并上浮);②SQLite 落库:jobs 表最小字段集(id TEXT 主键(本地生成,如 uuid v7)、kind、src、dst、status、engine_job_id、error、severity、created_at、updated_at;进度/校验和列属 WP06 不加);最小迁移框架(schema_migrations 表+版本号,单表 v1);库文件=用户数据目录下 partiverse.db,目录解析 core 内自实现(与 engine installer platform_data_dir 同语义约 25 行 std 实现,ADR-0004 否决 dirs 的同款口径,知会 Owner);③启动对账 JobManager::reconcile():引擎 ensure 后调 job/list,SQLite 中 status=running 且 engine_job_id 不在存活清单→置 error(cause=engine_restarted,Severity=Fatal);自动重排队属 WP06 重试策略,本卡不做;④状态推进 poll:job/status 轮询→done(取 ret)/error(取 error)→落库;单调用超时复用 T01;⑤ADR-0006:WP03 依赖集审计——rusqlite(bundled)候选:license 实测(非记忆,读 registry Cargo.toml)+deny 五节绿+商业授权核查(零商业授权预期;libsqlite3-sys crate 级许可 MIT OR Apache-2.0,partisync 同件先例在白名单内);若 deny 实测触线,本 ADR 一并裁定最小修正(multiple-versions=deny/wildcards=deny 语义不动,licenses 白名单扩充须逐项注释依据);core 新增 partiverse-engine path 依赖(向下依赖,合规);⑥集成测试(真实 rclone,离线):alias remote 本地目录互拷(rclone test makefiles 造数)submit→running→done 全链;reconcile 场景(rclone 重启后 running→error(engine_restarted));单测:状态机非法迁移表驱动+迁移框架版本断言。
