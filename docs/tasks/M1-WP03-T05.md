# [M1-WP03-T05] rc 客户端平台门修复:Windows 编译恢复(非 unix 显式 Fatal)
- 所属: M1-WP03 | 风险级: R1 | 预估: S
- SPEC: docs/specs/M1-WP00.md#WP03;平台口径=docs/adr/0005-wp02-rcd-supervisor-dependencies.md(非 unix 显式 Fatal 上浮,windows 目标编译不受影响)
- 背景: PR #13 CI 实证 windows smoke 编译失败(E0433:cannot find `unix` in `os`;client.rs:14 顶层裸引 `std::os::unix::net::UnixStream`)。根因=M1-WP03-T01 卡面未声明平台边界(卡面缺陷,立卡者责任,登记知会);实现按 unix 单平台交付无错(rcd.rs 同款边界已有 ADR-0005 先例)。本卡补平台门:Windows 恢复编译,非 unix 调用语义=显式 Fatal 上浮,零静默降级。
- 目标(DoD): ①client.rs 顶层 `use std::os::unix::net::UnixStream` 加 `#[cfg(unix)]`;②7 个带 `&UnixStream` 的 IO 帧自由函数(write_all_deadline/read_once/read_exact_deadline/read_line_deadline/read_reply/read_chunked_body/read_to_deadline_eof)各加 `#[cfg(unix)]`;③execute 拆双平台:unix 侧原实现加 `#[cfg(unix)]`(逻辑零改动),新增 `#[cfg(not(unix))]` 替身 impl(返回 `EngineErrorKind::PlatformUnsupported` + Severity::Fatal,零新错误变体、零新依赖);④集成测试 tests/rc_client.rs 文件头加 `#![cfg(unix)]`;⑤linux 五门禁复绿+PR CI 三 job(gates/linux、smoke/macos、smoke/windows)全绿。
- 文件清单: crates/partiverse-engine/src/client.rs, crates/partiverse-engine/tests/rc_client.rs
- 边界与自由度: 纯 cfg 门+非 unix 替身,已审逻辑零改动;client.rs 内 `#[cfg(test)] mod tests` 的 UnixListener 用法不触碰(test 模块 Windows check 不编译,若未来 Windows 跑 test 需另卡)。
- 禁止行为: 全局默认;额外=禁止改动已审函数体逻辑;禁止 TCP 回退路径;禁止生产路径 unwrap/expect。
- 完成定义: 代码+linux 五门禁绿+CI 三 job 绿。
- 验证方式: 输出归档 docs/reports/runs/M1-WP03-T05.md。
- 依赖: M1-WP03-T01(基于其分支)
- 状态: 待办
