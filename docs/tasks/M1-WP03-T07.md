# [M1-WP03-T07] jobs 集成 output 断言对齐 rclone 实际语义
- 所属: M1-WP03 | 风险级: R0(仅测试文件) | 预估: S
- SPEC: docs/specs/M1-WP00.md#WP04(§4 测试要求)
- 背景: PR #22 CI gates 首跑 `full_chain_then_reconcile` 于「Done 但 result 缺失」失败,且 T06 的 2 轮重试**连续两轮**均如此(error=None);而同内容 #23 全绿。定性实验(2026-10-10,本机 rclone v1.75.1 实机,Python 直驱 unix socket,20 轮 async sync/copy 轮询 job/status):output 字段 **20/20 存在**——本地无法复现,CI runner 上连续缺失。结论:`output` 非 rclone 协议保证字段(完成边界的可观察性因环境/时序而异),测试「Done⇒result.is_some()」断言超出协议保证;`JobManager::poll` 的 `result=None`(Done 路径)本就是产品语义内的合法返回。
- 目标(DoD): ①Done 分支断言改为 `error.is_none()`(成功判定),result 记录不强制存在;②T06 重试逻辑收窄:仅 `error.is_some()`(rclone 真失败)触发整链重试,error=None+result=None 接受为成功;③内容对账(dst mirrors src)保真不变=测试有效性不降;④本地门禁绿+CI gates 绿(本 PR 实证)。
- 文件清单: crates/partiverse-core/tests/jobs_real_engine.rs, docs/tasks/M1-WP03-T07.md(随分支), docs/reports/runs/M1-WP03-T07.md
- 边界与自由度: 产品代码(src/)零改动(poll 语义本已正确);其余测试不触碰;重试上限维持 2 轮。
- 禁止行为: 全局默认;额外=禁止放宽 error 判定(失败仍必须整链重试后 panic);禁止改 src/;禁止删内容对账。
- 完成定义: 代码+本地门禁绿+CI 三 job 绿。
