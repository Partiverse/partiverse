## 1. 目标与范围

- **目标**:交付 03 计划 §3 的 V1「统一浏览器」MVP(桌面三端,工期 2026-11 ~ 2026-12,约 2 个月)。
- **内置 Node 清单**:本地磁盘;SMB/FTP/SFTP/WebDAV/HTTP;S3 及兼容;OneDrive;Google Drive(`drive.file`,✅D7);Dropbox;Box;pCloud;MEGA;iCloud Drive(实验性,✅D18);坚果云(WebDAV+配额适配);**123 云盘(开发期=开发者自账号 dogfood)**;**百度网盘(个人使用应用免审;默认沙箱目录 /apps/{appname})**。
- **非目标**:挂载为系统盘(V2,✅D16/D9);AI 语义搜索(V3,✅D13/D21);partisync 集成(V2,✅D19);移动端(V3);社区/逆向驱动(合规红线)。

## 2. 设计基线与关键供应商事实

- 架构 v1.0(引擎=rclone rcd sidecar 单实例+槽位化;凭据=加密 config+keychain;数据面=回环 serve http)。
- **2026-10-08 核实的范围性事实(已并入验收)**:
  1. 百度:「个人使用」应用免审创建即上线(开发/内测不受阻);**默认沙箱 /apps/{appname},扩权走白名单**;OAuth 回调须公网地址 → 本地换码用 oob 式;token 过期=20016;
  2. 123:OpenAPI 须购权益包(社区口径约 ¥20/月);**用户级 OAuth 仅企业**→ M1 只做自账号 dogfood,面向用户的接入排 M2+(D11 企业签约后);
  3. GDrive:`drive.file` 限制=V1 仅管理本应用创建的文件,UI 明示+引导自建 client(✅D7/Q2);
  4. **123 单轨(2026-10-08 Owner 修订,替代 v0.2 双轨)**:**仅官方 WebDAV**(VIP 用户自生成应用专用密码接入,引擎 webdav 后端覆盖,开发者零成本);OpenAPI 通道**暂缓**(权益包仅自账号、用户级 OAuth 仅企业——对普通用户不适用),官方政策变更后再评估;

## 3.1 实现边界(反走捷径约束,Owner 指令 2026-10-08)

每个 WP 开工前按模板 T1 立任务卡,卡内**必须**含:①允许触碰的文件清单(锁死);②**禁止行为清单**(见下);③完成定义=代码+测试+证据三件套;④自由度声明(卡内未声明的决策一律上报,不得自行发挥)。
**全局禁止行为**(违反即评审否决):禁止 TODO/占位/桩实现冒充交付(mock 仅限测试且命名 Fake*);禁止吞错/静默降级(错误必须映射到 Severity 并上浮 UI 或日志);禁止生产路径 unwrap/expect(统一错误体系);禁止硬编码端点/路径/密钥(一律配置化,123 WebDAV 域名等按知识库"不硬编码"条);禁止超范围文件改动;禁止未经 ADR 引入依赖(铁律 8:含商业授权备选);禁止"先跑通再说"的临时协议/数据结构直进 main。
