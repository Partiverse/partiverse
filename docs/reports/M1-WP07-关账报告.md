## 3. CLI dogfood 命令面(Owner 可直接使用)
```
pv engine install|ensure|probe|status|shutdown
pv connection create-local <name> --path <dir>
pv connection create-webdav <name> --url <端点> --user <账号> --pass <应用专用密码>
pv connection list|delete
pv ls <remote:path>
pv mkdir <remote:path> | pv rm <remote:path>(确认)
pv copy|move <srcFs> <dstFs> [--wait]
pv jobs list [--status] [--watch] | poll <id> | cancel <id> | retry <id> ... | reconcile
```
注:按次启动,CLI 退出=引擎退出=运行中 job 终止;长传输用 --wait;重启后 jobs reconcile 对账。
